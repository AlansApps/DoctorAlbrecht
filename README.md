# TarjetAlan

App web (PWA) de estudio con learning cards: medicina funcional e integradora aplicada a ginecología y fertilidad, en español e inglés, con repaso espaciado y uso sin conexión.

**Abrir la app:** https://alansapps.github.io/TarjetAlan/

Herramienta educativa para profesionales; no es un título acreditado ni sustituye el juicio clínico.

## Desarrollo

```bash
npm install
npm run dev      # servidor local
npm test         # tests
npm run build    # build estático en dist/
scripts/deploy.sh   # publica dist/ en GitHub Pages (desde main)
```
